## 🚀 How to Run in Browser

If your faculty wants to test the code without downloading or installing compilers:
1. Click the **[Run Online](https://www.onlinegdb.com/online_c++_compiler)** or **[OneCompiler](https://onecompiler.com/cpp)** badge above.
2. Paste the contents of [`Experiment-1/fibonacci.cpp`](./Experiment-1/fibonacci.cpp).
3. Click **Run** and enter your desired number of terms in the input console.

---

## 💻 Local Compilation & Execution

```bash
# Navigate to the experiment folder
cd Experiment-1

# Compile with G++
g++ fibonacci.cpp -o fibonacci

# Run the executable
./fibonacci
```
